# StepX Neo Studio 1.2.3

面向 STEPX Neo 的独立第三方客户端。包名 `studio.jiayu.neo`，Android 11 / API 30 以上，target SDK 36。

## 1.2.3 一键云端接力开发

在本地项目列表点 **云端接力**，或在编辑器点 **云端接力开发 ↗**。长按项目菜单也提供同一入口。

- 自动将当前源码和图片资源上传到已关联的 Studio 项目；首次接力会创建并关联云端项目，再继续上传。
- 文件全部回读核验通过后，打开同一个云端项目，并填入接力草稿。补充本轮具体修改后发送；已有未发送草稿会先询问是否替换。
- 云端冲突、本地文件变化、部分上传失败或未确认的上次创建结果都会停止接力，不重复创建项目，也不在上传失败后提交开发任务。
- 需要登录官方 Studio。接力只上传项目源文件及资源，聊天配置、绘图密钥和对话历史不随项目同步。云端原有的其他文件仍遵循现有上传规则保留，不自动删除。

云端接力已通过上传模拟服务和原生状态校验；真实账号的完整接力流程仍待验证。

## 美术生成与本地项目（1.2.3 实机验证）

在本地项目中打开 **美术资源 → 绘图 API**。绘图配置与聊天模型独立，支持 OmniaKey 异步媒体任务、Images 兼容接口，以及自定义 JSON 请求和图片返回字段。密钥由原生端加密保存，不随项目或 APK 导出。

1. 保存服务地址、密钥和绘图模型，可检测候选模型或手动填写 ID。模型列表不代表每个模型均有调用权限。
2. 在“美术资源”选择配置，输入画面描述，生成后保存到当前项目。支持自动插入 HTML；TSX、CSS 等可指定文件中的唯一占位符，替换为本地图片路径。
3. 开启“允许 AI 助手调用绘图 API”，在指定项目的对话中提出美术需求。助手可以通过 `list_art_models`、`list_assets`、`generate_image` 查询、复用、生成和引用图片；每轮最多三次调用，每次取一张图片。
4. 图片保存在项目的 `binaryFiles` 中，自动参与离线预览、源码 ZIP、云端同步和 APK 构建。公共目录图片使用 `/文件名.png` 引用。图片先保存，后续代码生成失败也不会丢失，可继续引用已有资源。

Neo 实机已验证 OmniaKey 的 `gpt-image-2` 生成图片、保存并自动引用、本地离线预览、本机构建 APK，以及安装后显示同一张图片。AI 工具循环、Images 兼容与自定义异步协议使用可控服务验证；其他服务和模型需按实际接口测试。

当前输出转为保留透明度的 PNG，最长边不超过 1024px，单文件不超过 1 MB；项目总容量仍为 4 MB。暂不支持参考图编辑、视频或流式图片输出。生成图片按服务商规则计费；有明确 Token 响应时计入第三方 API 账本，缺失计量时标记未知，不估算 Token。

自定义协议支持 `{{prompt}}`、`{{model}}`、`{{size}}`、`{{quality}}` JSON 字符串占位符；返回路径使用 `data.0.url` 等点分路径。可配置同服务的任务查询地址及状态字段。密钥仅发送给配置的 API；图片下载不携带密钥。异步等待最多五分钟，可停止等待并恢复原任务。停止等待不等于取消远端任务；OmniaKey 在提交结果不明时使用原幂等键恢复，其他接口没有任务 ID 时不会自动重发。

- **对话新建项目**：直接说“新建一个待办项目”，助手会创建独立本地项目、绑定新对话并写入代码；后续对话继续修改同一项目。失败或退出保留已创建项目，未完成代码不覆盖旧文件。
- **单个与批量上传**：项目行 ↑、长按菜单和编辑器均可上传；“全部上传同步”默认全选，也可取消部分项目。顺序处理并保留逐项目结果，冲突不覆盖，失败继续下一项，停止后保留已核验记录。首次创建结果不明时阻止自动重复创建，需核对关联。

- **端侧 AI**：Gemma 4 E4B 使用 LiteRT-LM 在手机GPU运行，Android模型包32K上下文、MTP及官方采样参数；支持 Hugging Face 文件列表、断点下载、SHA-256校验和自定义 `.litertlm` 文件导入。权重需另行下载。其他格式（如GGUF）当前不支持。
- **开发工具**：助手可读取/搜索项目、暂存修改、本机编译检查、预览、构建根目录Web APK和获取日志；实时展示新增/修改代码，正在处理的项目显示绿色闪烁提示。默认先检索GitHub参考，可关闭后离线开发。复杂原生Android/Node/任意npm依赖仍需外部环境。
- **官方连接器**：39个连接器、358项能力说明；可搜索、查看、同步、纳入项目说明，AI可按需调用查询工具。实际设备能力需要官方目标项目的授权与运行环境。见 [连接器用法](连接器目录.md)。
- 对话滚离底部时显示仅含向下三角形的一键到底按钮。

- AI 对话历史采用侧边抽屉，支持搜索、多选、全选当前列表和确认删除；保留项目与 Token 账本。

- DeepSeek 官方接口使用 1,048,576 Token 上下文窗口，移除原先80,000/95,000字符及100条消息的限制；输入与输出共同占用上下文，最终以服务端分词校验为准。单次输出参数独立设置，最高393,216 Token。
- Token账本默认显示累计用量，自动汇总全部本地及已读取的Studio项目；第三方API、阶跃API、Studio日志和本地模型分别统计。重复报告只使用同项目的最新快照，未读取或缺失计量标为未知。
- 移除App内背屏点阵工坊入口及操作；已有项目文件保留。
- 应用内更新使用本仓库发布版本。

参数来源：[DeepSeek官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/)。`deepseek-v4-flash`是官方仍接受的旧名称，当前由Flash系列现行模型提供服务。

## 1.1.8 在 Neo 本地运行

打开本地项目，点 **本地运行 ▷**。同步下来的 React/TSX 项目也能在手机上编译和运行；保留旁边的云端入口。编译器与常用依赖内置于 APK，运行不需要 Mac、云端编译或下载依赖。修改源码后关闭预览，再点本地运行即可重新编译；预览的“重载”只重新运行当前快照。

- 支持 HTML/CSS/JS、ES modules、TypeScript/TSX、React 19、Tailwind 3 样式、`@/` 与 tsconfig 简单路径别名、JSON、多级目录、图片与二进制资源。
- 内置 React/ReactDOM 19.3.1、React Router 7.18.4、Lucide 0.577.0、clsx 2.1.1、tailwind-merge 2.6.1、Supabase JS 2.117.1、xgplayer 3.0.26。只加载工程实际使用的依赖；未内置的包或不兼容版本会报出具体名称，不自动联网安装。
- 运行页默认断网；需要 HTTPS 接口/远程资源可手动打开“联网”，仍受浏览器 CORS 限制。每个项目的本地存储按独立来源隔离，重开可保留。预览没有工作台 API 密钥、Android 桥接或设备权限。
- 点运行页状态可查看兼容说明。Vite/Node 脚本、服务端、原生 Step 桥接、Tailwind 配置插件未执行；环境变量不自动从账号或云端注入。涉及这些能力的项目需单独配置或走云端/独立 App。
- **本地运行与独立 APK**：1.2.1 起，HTML 和内置依赖范围内的 React/TSX 项目均使用同一编译器完成本机预览与 APK 构建。任意原生 Gradle 工程仍需相应构建环境。

界面品牌统一为 StepX Neo，去除模型厂商联名宣传。服务商名称仅在配置、模型选择及用量等必要位置保留。

## 1.1.7 AI 助手开关与云端源码同步

- 在本地项目页「功能与显示设置」或右上角「⋯」开关 AI 助手。关闭后底栏隐藏 AI 入口、其余入口均分空间，顶部联动入口也隐藏；模型配置、对话、Token 记录保留，重启记住选择。运行中的 AI 任务须先结束。官方 Studio 和源码同步可独立使用。
- **同步云端项目 ↓**：选择已登录 Studio 账号的项目，直接读取源码保存为本地项目。保留子目录、中文文本及二进制资源；同一云端项目再次同步会更新已关联副本。
- **上传项目 ↑**：在本地编辑器点击。首次确认后创建并关联新的 Studio 项目，初始化工作区并上传；再次点击只更新有变化的文件，逐文件回读 SHA-256。中断保留已确认的关联，重试继续同一项目；创建响应未确认时先核对云端列表。
- **同步到本地 ↓**：已关联项目可直接拉取更新。以最近同步基线核对两边；独立改动可保留，同一文件两边都改时拒绝覆盖。云端删除的未修改文件同步删除，本地独立新增保留。同步前保留包含资源的恢复快照。
- 上传只新增/更新文件，**不会删除云端其他文件**。不发送 AI 开发指令，不自动发布 App，也不会把本地模型配置传到云端。

支持最多 300 个文件、单文件 1 MB、合计 4 MB。依赖目录、构建产物、`.env`、常见凭据与签名文件排除并显示清单；超限整体拒绝，不静默截取。可编辑云端文本源码并导出包含资源的 ZIP。1.1.8 支持内置依赖范围内的云端前端源码本地运行；独立 APK 与任意 Gradle 工程仍需相应构建环境。已有 HTML/根目录 ZIP 导入入口保持其原有限制。

请在同步前暂停 Studio 生成及其他编辑。接口没有服务端原子锁，上传前后检查不能保证多端同时写入时的事务隔离；失败会显示已核验数量，不自动回滚或强制覆盖。使用的是当日实机观察到的站内文件接口，官方变更后可能需要适配。

## 1.1.5 指定项目开发与 Studio 用量检查

AI 助手可选择本地项目，选择“直接修改”“先审查”或“只讨论”。每次发送由原生层读取目标项目的最新全部文本文件及调试报告；新增、修改、删除文件统一验证并原子保存，保留最近 5 次快照。请求绑定项目 ID 和文件基线，切换页面不会写错项目；并发改动、截断、取消、格式错误不覆盖文件。协作页的“实现任务”也走这条直接写入通道，ZIP 导入与审查应用复用原生校验。回复代码默认折叠，可继续预览和选择本机/云端构建。

Token 页新增“检查 Studio 用量”：先在 Studio 打开项目，再只读检查该项目的官方会话历史数字字段。2026-10-18 实测 5 个项目未返回主会话输入/输出用量，子任务 totalTokens 均为 0，因此总量仍显示未知。检查显示时间、项目、范围和原因；若以后子任务返回有效非零值，仅显示已报告部分，不冒充全账号账单、不并入第三方 Token。此适配依赖当日观察到的站内接口，非公开稳定 SDK；接口变化或登录失效会提示失败。

实机完成一次 DeepSeek 修改计数器 → 原项目落盘 → 触摸预览 → Neo 本机签名 APK → 安装点击验收。临时测试 App 已卸载。游戏项目使用相同 Web 文件通道，本轮没有对新游戏玩法作验收承诺。

## 1.1.4 本地项目删除

项目列表支持长按菜单和向左滑露出删除；右侧“⋯”提供同一菜单，方便点击和辅助功能使用。删除需原生确认，然后移到“最近删除”，保留完整源码、协作记录、文件快照和构建记录，可恢复或再次确认彻底删除。AI、联动、构建或交接任务进行时，暂不允许移动或彻底删除项目。

彻底删除只清理该本地项目及工作台内对应构建APK；云端项目、已导出文件、已安装App、独立AI对话和Token账本保留。最近删除不会自动过期，仍占用本机空间；需要清理时在最近删除逐项彻底删除。

延续1.1.3公开GitHub更新功能：右上角“⋯ → 检查更新”，查看说明后下载安装，Android最终确认。见[更新说明](更新说明.md)。

## 功能

- **检查更新**：公开 GitHub 正式版本检查、可选每天启动检查、说明与下载进度、取消、完整性与签名验证、Android 安装确认。
- **液态玻璃风格**：参考 Apple 官方材质与层级原则，独立实现 阶跃 AI 配色方向的 Android 深色玻璃控件、胶囊导航与柔和背景；代码与正文保持清晰底色。支持降低透明度、增强对比度及减少动态效果。不是 Apple 原生框架或认证。
- **Amoo 手机执行**：项目任务经原生预览打开 Amoo 分享入口，在可见会话发送；实测只读查询飞行模式成功。结果人工核对后写回共享项目，尚无后台自动发送或自动回调。
- **Neo 显示适配**：现代 edge-to-edge 安全区域、摄像头及手势区域避让、与页面背景协调的系统栏、键盘避让、横竖屏、可退出的专注模式。
- **官方 Studio**：独立登录、返回/前进/刷新/停止、桌面与手机版切换、文字及双指缩放、查找、分享、文件选择、HTTPS 下载、最多 10 MB 的 Blob/data 下载、系统下载列表、缓存清理与登录状态清理分开。
- **本地项目**：HTML/CSS/JavaScript 编辑、多文件、自动保存、撤销/重做、Tab、查找、复制、长按菜单/左滑删除、最近删除恢复、运行预览及 JS 错误提示、HTML/ZIP 导入、ZIP 导出。
- **自定义 AI**：多个 Base URL/完整端点、模型 ID、密钥、系统提示和输出上限配置；Chat Completions 兼容协议和 Anthropic Messages；检测 `/models`、模型搜索选择、手动模型 ID；多轮历史、取消请求、对话导出、读取指定项目全部文件、直接修改或审查后应用、回复 HTML 另存项目。
- **自动联动**：DeepSeek（或所选模型）规划 → 同一个 Studio 项目自动发送 → 等待新回执 → 模型审查，按需修正，最多 1–3 轮；保持前台。见 [自动联动说明](自动联动.md)。
- **紧凑布局**：正文 13px；页内大标题移至原生顶部栏；导航 48dp、底部外边距 0；手机 Studio 对话铺满宽度，消除右侧 16px 磨砂余边。
- **Token 账本**：Step／Studio 与第三方 API 分账，CSV 带 source 和 usage_known；Studio 记录确认送达的自动联动轮次，并可读取当前项目已落盘 SDK Token 报告、检查历史接口字段；未提供的范围明确标为未知。真实 usage、输入/输出/缓存读取/缓存写入/推理、耗时、今日/累计、按模型汇总、对话汇总、逐次明细、CSV 导出。未知用量明确标记，推理和缓存子项不重复累加。
- **项目协作**：共享目标、任务及验收状态、关联 Studio 项目、导入其页面可见文字、预览共享上下文、交给 Step 填入草稿、外部模型按规划/实现/审查职责接力、AI 实现直接写入、ZIP 文件建议审查后应用、应用前文件快照及恢复、交接 Markdown 导出、协作记录。

- **构建与调试**：本机编译 HTML / React / TSX 前端项目，包含嵌套资源、图片和内置依赖，生成独立签名 APK；支持“构建并安装到 Neo”或导出 APK，也可选择 Step 云端构建。应用日志与测试报告可回传，生成 App 经用户确认调用已有 AI 配置。见 [接口文档](调试接口.md)。

## 使用

1. 打开手机上的 **StepX Neo Studio 1.2.3**。
2. **Studio**：官方账号登录后继续使用其云端构建能力。
3. **本地项目 → 新建项目**：编辑代码，点“运行”。本机读取项目快照，编译支持的前端源码；默认断网，可手动开启 HTTPS 网络，不开放文件系统和设备权限。
4. **AI 助手 → 设置**：填写服务商名称、HTTPS 地址、API Key，点“保存并检测模型”，搜索/选择模型或手填 ID，再保存。检测模型列表不发起文本生成；“保存并测试”会发起一次短生成请求，可能计费。
5. **编辑器 → 项目协作**：填写共享目标、建立任务、关联 Studio 的具体项目网址。实现任务自动写入此项目，保存快照；回到编辑器验证后再将任务标记“已验收”。
6. **交给 Step**：将共享上下文填入 Studio 可见输入框。已有未发送草稿会询问是否替换；找不到输入框则复制交接内容，由用户粘贴。不会自动提交构建。
7. **从 Step 返回**：打开关联项目的对话或结果页面，导入页面文字并核对。若取得代码 ZIP，可导入为文件修改候选，经审查应用。不同 API 可继续使用这些共同上下文。
8. **本地项目 → 编辑器 → 构建 APK**：点“构建 APK”后可导出文件；点“构建并安装到 Neo”会在编译完成后打开 Android 安装确认。首次安装需允许 StepX Neo Studio 安装应用，返回后再点“安装到 Neo”。云端下载的前端源码也可本机打包；需要官方原生能力时，打开关联 Studio 项目走官方“真机测试”。生成 App 的原生菜单可开启调试并回传报告。
9. **自动联动**：在项目协作顶部填写本次任务、选 API 和轮数，点开始；确认后保持前台，自动完成往返。可随时停止后续步骤。
10. **Token**：分开查看 Step／Studio、第三方 API；阶跃官方 API 与 Studio 仍区分子账，按模型查看或导出 CSV。

DeepSeek 兼容旧模型名称时，用量按服务商实际返回的模型记录。模型配置与密钥保存在设备上，不包含在源码或 APK 中。

## 边界

- 官方 Studio 的服务端模型、费用和 token 不受本地配置控制。本工作台记录本应用 API 通道返回的 usage；Studio 可通过当前登录项目的只读诊断读取已落盘 SDK 用量；项目日志之外的完整总量和套餐余额仍未知，不估算或视为零；没有读取 Amoo 或其他 App 的用量。
- 现在支持**前台有界自动消息往返**，不是自动双向源码同步。没有公开的 Studio 项目读写 SDK 被验证；没有自动双向源码同步、文件锁或后台合并；Studio 的服务端模型不能用 DeepSeek 直接替换。
- API 支持流式生成；普通兼容接口单次输出可设 64–32768 Token，官方 DeepSeek 上限为 393216 Token；不支持 Responses 协议、模型图片生成或自动执行模型生成的终端命令。厂商模型对参数的支持可能不同。
- 模型检测使用服务商 `/models` 首次响应；不支持该接口或有分页时，可手动填 ID。兼容别名可能不列在模型目录里。
- 本机构建与运行预览使用同一离线前端编译器，支持 HTML / React / TSX、嵌套目录、二进制资源、`public/` 静态资源及内置依赖。源码快照最多 300 文件、单文件 1 MB、合计 4 MB；编译输出最多 400 文件、单文件 8 MB、合计 16 MB。缺失或不兼容依赖会停止构建并显示原因。运行壳预先编译；不运行任意 Vite 插件、Node 服务端、Gradle 或 npm 安装，也不自动注入官方 Studio 原生 SDK。需要这些能力的项目仍须云端或外部构建环境。
- ZIP 导入最多 40 个**根目录文本文件**、总解压大小 2 MB，须有 `index.html`。不是通用 Android/React/Node 工程导入器。协作文件应用限 40 文件、45 万字符，保留最近 5 个应用前快照。
- 本地资料是应用私有数据，卸载会删除；请导出项目、对话和 Token 明细。APK 下载通过系统下载/文件管理器交由用户安装，不自动安装其他包。
- 麦克风/摄像头只对 `https://studio.stepx.com` 当前网页请求逐项询问；不会授权未知 WebView 资源。SSL 错误不忽略。

## 数据与安全

本机生成的 App 使用独立包名与权限，仅其自身网页有 NeoDev 接口。每次 AI 请求都经原生确认，密钥留在 Neo Studio。

原生 Java 保存配置、项目和记录，使用 AtomicFile。API Key 由 Android Keystore AES-GCM 加密；应用禁止备份。官方 Studio WebView 和代码预览没有 `Neo` 原生桥接对象。本地界面仅加载包内资源，CSP 禁止外部脚本、网络和 frame，仅允许读取包内第三方许可证文本。模型输出以转义文本显示，只有用户点击运行时才执行预览代码；自动写入不自动执行或安装代码。

API 只接受 HTTPS（测试构建仅对 localhost 有受控例外），不跟随重定向，防止密钥被重定向转发。更换已有配置的端点必须重新填写密钥。失败、取消、无 usage 记录为未知，服务商仍可能计费。

## 构建

使用本机已存在的 Android SDK 36 / build-tools 36.0.0 与 Temurin JDK 25；没有 Gradle/AndroidX；实际依赖 apksig-android 4.4.0 进行设备端 APK 签名，许可见 ATTRIBUTION.md。

```sh
./build-runtime.sh
./build.sh debug
./build.sh release
```

可通过 `ANDROID_SDK_ROOT`、`JAVA_HOME`、`NEO_SIGNING_DIR` 指定路径。签名材料由 `NEO_SIGNING_DIR` 指定，目录 0700、文件 0600，不在项目中。`out/` 为可重建产物；`dist/` 为 APK 和 SHA-256。

`debug` 包仅供本机开发，开启 WebView 调试及测试环境。正式交付只使用 `release` 包。测试说明与真实验收见 [开发日志](开发日志.md) 和 `evidence/`。
